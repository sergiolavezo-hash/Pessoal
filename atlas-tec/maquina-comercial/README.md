# Máquina Comercial Atlas Tec

Sistema completo de aquisição de clientes B2B para a Atlas Tec ([atlas-partner.com](https://atlas-partner.com/)) — da prospecção ao contrato assinado.

> **Princípio fundamental:** nunca abrimos conversa apresentando a empresa. Abrimos pelo **PROBLEMA → IMPACTO → HIPÓTESE → CURIOSIDADE → CONVERSA**. O objetivo da primeira abordagem não é vender — é conseguir uma resposta.

## Regra de ouro

Nada aqui é "dica de vendas". Toda ação segue o formato:

**O QUE FAZER → COMO FAZER → O QUE FALAR → PARA QUEM FALAR → QUANDO FAZER → QUAL PRÓXIMO PASSO**

E nenhuma interação comercial termina sem o próximo movimento definido.

## As 9 perguntas que guiam qualquer conta

1. Onde está o dinheiro?
2. Quem tem o problema?
3. Quem sente a dor?
4. Quem decide?
5. Qual é o gatilho de compra?
6. Por que compraria agora?
7. Por que compraria da Atlas?
8. O que pode impedir o fechamento?
9. Qual é o próximo passo necessário para avançar?
