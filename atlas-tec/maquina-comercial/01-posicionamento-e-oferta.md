# 01 — Posicionamento e Oferta

## O que a Atlas Tec é (base: atlas-partner.com)

A Atlas Tec é "o elo entre empresas e especialistas, garantindo performance, inovação e crescimento sustentável". Nasceu com a visão de **transformar dados em resultados** e conecta os melhores talentos a grandes projetos.

**Serviços:**
- Business Intelligence — estruturação e análise de dados para gerar insights estratégicos
- Data Science — transformação de grandes volumes de dados em conhecimento
- Data Management — otimização da gestão de dados para decisões eficientes
- Cloud (parcerias Google, Microsoft e AWS)
- Outsourcing — alocação de especialistas em desafios estratégicos
- Software Development — desenvolvimento de soluções digitais
- Consultoria estratégica, treinamentos e suporte técnico

**Diferenciais reais (usar apenas estes — não inventar cases, clientes, números ou certificações):**
- Experiência sólida em projetos de Business Intelligence
- Parcerias com Google, Microsoft e AWS
- Modelo flexível de alocação de talentos
- Abordagem tecnológica agnóstica
- Capacidade de atuar em projeto fechado OU alocação/outsourcing

## O que NÓS vendemos (e o que nunca vendemos)

**Nunca vendemos:** horas de consultoria, "apresentação da empresa", tecnologia pela tecnologia.

**Sempre vendemos:** resultado + capacidade técnica + velocidade + redução de risco + acesso a especialistas + flexibilidade + solução para um problema empresarial.

## Tradução oferta → dor (usar sempre esta linguagem)

| Em vez de dizer | Diga |
|---|---|
| "Temos Data Engineering" | "Podemos aumentar a capacidade do seu time de dados sem precisar esperar meses para contratar especialistas." |
| "Temos BI" | "Podemos acelerar a transformação de dados operacionais em indicadores que o negócio consiga usar para decidir." |
| "Temos outsourcing" | "Podemos aumentar rapidamente a capacidade técnica da equipe sem transformar toda necessidade em contratação permanente." |
| "Temos desenvolvimento" | "Podemos assumir uma frente específica do backlog para liberar seu time interno para o que é estratégico." |
| "Temos Data Science" | "Podemos transformar o volume de dados que vocês já têm em modelos que reduzem custo ou aumentam receita — sem montar um time do zero." |
| "Temos Cloud" | "Podemos tirar a migração/modernização do papel com especialistas certificados nos três grandes provedores, sem parar a operação." |
| "Temos Data Management" | "Podemos fazer o dado chegar confiável na ponta — hoje cada área tem um número diferente e ninguém confia no relatório." |

## Proposta de valor por cenário do cliente

| Cenário do cliente | Dor típica | Oferta Atlas | Mensagem central |
|---|---|---|---|
| Montando área de dados | Não consegue contratar; não sabe por onde começar | Outsourcing + Data Management | "Estruture a área com especialistas desde o dia 1, sem errar as primeiras contratações." |
| Time de dados sobrecarregado | Backlog de demandas do negócio; fila de meses | Alocação de squad/profissionais | "Capacidade extra em 2–3 semanas, não em 6 meses de recrutamento." |
| BI travado / relatórios manuais | Decisão no Excel; números divergentes | BI + Data Management | "Indicadores confiáveis e automatizados para quem decide." |
| Migrando para Cloud | Falta de especialista; medo de risco/custo | Cloud + parceiros GCP/Azure/AWS | "Migração com quem já fez, com custo previsível." |
| Projeto de IA anunciado | Pressão do board; dados não prontos | Data Science + Data Management | "IA só funciona com dado pronto — preparamos a base e entregamos o primeiro caso de uso." |
| Backlog de software atrasado | TI apagando incêndio; roadmap parado | Software Development | "Assumimos uma frente inteira e devolvemos previsibilidade ao roadmap." |
| Pós-fusão/aquisição | Sistemas e dados duplicados | Data Management + Desenvolvimento | "Unificamos dados e sistemas para a sinergia da operação aparecer no resultado." |

## Frases proibidas

- "Somos uma empresa de tecnologia e gostaríamos de apresentar nossos serviços."
- "Gostaria de apresentar nossa empresa."
- "Somos referência." / "Somos líderes." / "Temos soluções inovadoras." (sem evidência concreta)
- "Meu nome é X e faço parte da Atlas…" como abertura de e-mail.

## Tom comercial

Confiante, consultivo, inteligente, direto, executivo, humano. Sem excesso de formalidade. Sem parecer vendedor desesperado. Fatos, contexto e problemas reais — sempre.
