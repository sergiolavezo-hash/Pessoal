# 03 — Personas

Nunca tratar todos os cargos da mesma maneira. Quatro grupos, quatro conversas diferentes.

## Grupo 1 — C-Level (CIO, CTO, CDO, Chief Digital Officer)

| Dimensão | Detalhe |
|---|---|
| **Dores** | Pressão do board por resultado da tecnologia; prazos de transformação; dependência de poucas pessoas-chave; custo crescente de TI; risco de projetos estratégicos falharem |
| **Objetivos** | Entregar a agenda de transformação; mostrar ROI; reduzir risco; previsibilidade |
| **Indicadores** | Time-to-market, custo de TI vs. receita, entrega do roadmap estratégico, adoção de dados pelo negócio |
| **Preocupações** | Reputação, segurança, lock-in de fornecedor, qualidade de parceiro |
| **Linguagem** | Negócio e risco — nunca detalhe técnico. Falar de resultado, prazo, capacidade e flexibilidade |
| **Gatilhos** | Novo mandato (acabou de assumir), anúncio público de projeto, M&A, pressão por IA |
| **Objeções típicas** | "Já temos parceiros homologados"; "isso é com meu diretor de X" |
| **Argumento** | "Capacidade sênior sob demanda para garantir a agenda estratégica sem inflar estrutura fixa" |
| **CTA ideal** | Conversa executiva de 20 min sobre um desafio específico da agenda pública dele |

## Grupo 2 — Lideranças (Diretores e Heads de Tecnologia, Dados, BI, Engenharia, Analytics, Cloud, Transformação Digital)

| Dimensão | Detalhe |
|---|---|
| **Dores** | Backlog maior que a capacidade; demora para contratar; turnover; cobrança de cima e de baixo; fila de demandas do negócio |
| **Objetivos** | Entregar o roadmap; proteger o time; crescer a área com qualidade |
| **Indicadores** | Velocidade de entrega, SLA de demandas, satisfação das áreas de negócio, vagas preenchidas |
| **Preocupações** | Qualidade técnica de quem chega; curva de rampagem; gestão do parceiro dar mais trabalho que ajuda |
| **Linguagem** | Capacidade, entrega, velocidade, qualidade — meio técnico, meio gestão |
| **Gatilhos** | Vagas abertas há tempo demais; projeto novo aprovado; perda de pessoas-chave |
| **Objeções típicas** | "Já temos fornecedor"; "prefiro contratar interno"; "outsourcing já deu errado aqui" |
| **Argumento** | "Especialista validado produzindo em 2–3 semanas, com flexibilidade para escalar ou reduzir" |
| **CTA ideal** | Call de 15 min para entender o gargalo de capacidade — **é a persona de entrada preferencial** |

## Grupo 3 — Influenciadores técnicos (Data/BI/Analytics/Cloud/Engineering Managers, Arquitetos, PMs)

| Dimensão | Detalhe |
|---|---|
| **Dores** | Sprint estourando; dívida técnica; pipelines quebrando; time júnior demais para o desafio |
| **Objetivos** | Entregar com qualidade; não ficar refém de gambiarras; aprender/usar boas tecnologias |
| **Indicadores** | Velocidade do time, qualidade/incidentes, cumprimento de sprint |
| **Preocupações** | Receber gente fraca de consultoria; retrabalho; "vender" a ideia para o chefe |
| **Linguagem** | Técnica e concreta — stack, arquitetura, casos práticos |
| **Gatilhos** | Projeto travado, tecnologia nova sendo adotada, pipeline/plataforma instável |
| **Objeções típicas** | "Consultoria manda júnior e cobra sênior"; "a gente resolve internamente" |
| **Argumento** | "Perfis validados tecnicamente, na stack de vocês (GCP/Azure/AWS, agnóstico), com senioridade real" |
| **CTA ideal** | Conversa técnica entre pares; oferecer envolver especialista da Atlas. Papel no deal: **campeão interno** — municiar com material para vender internamente |

## Grupo 4 — Compradores (Procurement, Suprimentos, Vendor Management, Strategic Sourcing)

| Dimensão | Detalhe |
|---|---|
| **Dores** | Pressão por saving; risco de fornecedor; compliance; homologação demorada |
| **Objetivos** | Fechar bom contrato, com segurança jurídica e preço defensável |
| **Indicadores** | Saving, prazo de contratação, risco/compliance do fornecedor |
| **Preocupações** | Fornecedor pequeno demais, sem documentação, sem saúde financeira |
| **Linguagem** | Formal, comparativa, orientada a custo total e risco |
| **Gatilhos** | Área técnica já convencida abrindo processo de homologação |
| **Objeções típicas** | "Precisa entrar na concorrência"; "o rate está acima do benchmark" |
| **Argumento** | Flexibilidade contratual, transparência de composição de custo, comparação por senioridade real (não só rate/hora) |
| **CTA ideal** | Nunca é porta de entrada. Entra no processo depois, com a área técnica como aliada. Preparar documentação cedo |

## Regra de sequenciamento

1. **Entrada:** Grupo 2 (lideranças) — sentem a dor e têm autoridade.
2. **Paralelo:** conexão com Grupo 3 (influenciadores) para validação técnica e inteligência da conta.
3. **Elevação:** Grupo 1 (C-Level) quando o deal for estratégico ou quando a liderança travar.
4. **Final:** Grupo 4 (compras) — chegar com a área técnica já vendida.
