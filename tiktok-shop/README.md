# Operação TikTok Shop

Central de operação para maximizar comissões como afiliado do TikTok Shop.

## Estrutura

| Arquivo/pasta | O que é |
|---------------|---------|
| `prompt-mestre.md` | Instruções completas da operação (fonte da verdade) |
| `playbook.md` | Sistema operacional: rubrica de notas, fórmulas financeiras, benchmarks, matriz de testes, funil, calendário, MODO MÁQUINA DE VENDAS |
| `templates/analise-produto.md` | Template de análise com nota de oportunidade |
| `templates/roteiro-video.md` | Template de roteiro (hook, cenas, CTA, legenda, resultado) |
| `templates/matriz-testes.md` | Matriz 5 ângulos × 2 hooks |
| `templates/roteiro-live.md` | Estrutura de live em blocos de 15 min |
| `templates/tracking-metricas.md` | Tracking semanal de comissão |
| `pesquisa/` | Pesquisas de tendências datadas |
| `produtos/` | Análises de produtos individuais (uma por arquivo) |

## Fluxo de trabalho

1. **Garimpo** — filtrar produtos no Central de Afiliados (critérios em `pesquisa/`)
2. **Análise** — cada produto passa pela rubrica do `playbook.md` → EU TESTARIA OU NÃO TESTARIA?
3. **Teste** — matriz 5 ângulos × 2 hooks (10 vídeos)
4. **Leitura** — decidir por comissão/1.000 views, nunca por views
5. **Escala** — vencedor vira 10–30 variações + live + (se ROAS > 1,5) mídia paga
